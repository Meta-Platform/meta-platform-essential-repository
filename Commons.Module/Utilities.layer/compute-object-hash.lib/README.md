# compute-object-hash.lib

- **Tipo:** biblioteca (`.lib`)
- **Namespace:** `@/compute-object-hash.lib`
- **Localização:** `Commons.Module/Utilities.layer/compute-object-hash.lib` (EssentialRepo)

## Propósito

Calcula um **hash determinístico** a partir de um objeto/valor. É usado, por
exemplo, para nomear ambientes de execução (nome do pacote + hash do caminho).

## Exports (`src/`)

| Módulo | Responsabilidade |
|--------|------------------|
| `ComputeObjectHash.js` | Gera o hash de um objeto. |
